# Guia de Testes – SGEA

## Estratégia adotada

Devido às restrições de tempo do projeto, não foram elaborados roteiros formais
de testes manuais ou automatizados.

A validação do sistema foi realizada por meio de:
- Execução contínua durante o desenvolvimento
- Testes exploratórios manuais pontuais
- Verificação das regras de negócio nos models e views

## Observação
A ausência de testes formais não compromete o funcionamento básico do sistema
no contexto acadêmico do projeto.
